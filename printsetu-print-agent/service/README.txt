PrintSetu Print Agent — Setup
=============================

This lets your PrintSetu shop dashboard send print jobs straight to a
printer on this computer.

HOW TO INSTALL
1. Double-click "Install.bat".
2. Windows will ask for permission to install a background service —
   click "Yes".
3. Wait a few seconds. You'll see a message telling you whether your
   shop connected successfully.
4. That's it — you can close this window. The Print Agent will now
   start automatically every time this computer turns on, and it will
   restart itself automatically if it ever crashes.

HOW TO UNINSTALL
Double-click "Uninstall.bat" (also asks for permission) if you ever
need to remove it from this computer, for example before moving the
agent to a different PC.

TROUBLESHOOTING
- If your shop doesn't show as "Online" on the dashboard after a
  minute, make sure this computer is connected to the internet.
- Logs are saved next to this file, in the "logs" folder, if PrintSetu
  support needs to look into an issue.
- This agent is tied to one shop and one credential. If you need a
  fresh copy (e.g. a new PC), download it again from your PrintSetu
  dashboard rather than copying this folder to another machine.
